# PizzaOrderDesktopApp
JavaFX Pizza Order System: A high-performance desktop app leveraging MVC architecture &amp; OOP principles. Features a dynamic List-based Order Model, MenuItem inheritance, and real-time pricing logic for custom pizzas &amp; family deals. Optimized for seamless UX with itemized billing &amp; robust JPA-ready backend structure. Smart, Scalable, &amp; Secure.

PizzaOrderApp is a sophisticated JavaFX-based management system that transforms a basic pizza calculator into a professional, multi-item ordering platform. The application allows users to build highly customized pizzas selecting specific flavors, sizes, premium crusts like Deep Dish, and specialized sauces which can then be added to a virtual cart.

Unlike simple calculators, this system manages a complex List-based Order Model, enabling customers to combine multiple custom pizzas with fixed-price "Family Deals" in a single session. The project demonstrates a robust Model-View-Controller (MVC) architecture and leverages core Object-Oriented Programming principles like inheritance and polymorphism through a unified MenuItem base class. By integrating real-time total calculations and a detailed, itemized bill summary, the app provides a seamless and transparent user experience tailored for modern food service requirements.

Key Technical Features to Include: Object-Oriented Foundation: Uses a MenuItem abstract class to treat individual pizzas and bundle deals as unified objects.

Dynamic Order Container: Features an Order class that acts as a live cart, tracking multiple items and calculating complex totals on the fly.

Smart Pricing Logic: Implements refined math to ensure base prices are established before applying premium add-ons for 100% accuracy.

Advanced UI/UX: Provides a "Live Preview" of current selections alongside a "Final Summary" to ensure user clarity before checkout.
